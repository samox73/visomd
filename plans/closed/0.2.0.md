# visomd 0.2.0 plan

Four additions to the 0.1.0 pipeline, independent of each other: images, a pager mode, clickable links, light terminals. Math rendering does not change.

## Carried over from 0.1.0

- Settings live in one place: the `Settings` struct in `main.rs`, fed by flags and `~/.config/visomd/config.toml`, printed by `--print-config`. Every new option (`pager`, `theme = "auto"`) goes there, so the printed config stays complete.
- `--completions SHELL` is generated from the clap definition; new flags appear in it for free.
- Terminal queries go through `Tty::query` with a one-second silence timeout and a trailing DA1; the OSC 11 background query reuses it.
- `assets/screenshot.nu` re-shoots `assets/demo.png` on a headless sway (`nix shell nixpkgs#sway nixpkgs#grim nixpkgs#imagemagick -c nu assets/screenshot.nu`). Never open windows on the live desktop for this. Re-shoot after any visible change, and add a light-background shot once `theme = "auto"` exists.
- Non-goals, decided: no `\[ \]` or `\( \)` math delimiters (only the `$` syntax pulldown-cmark implements), no macro preamble, no `physics` package.
- Start by moving this file to `plans/active/` with `git mv`; move it to `plans/closed/` when 0.2.0 is tagged.

## Settled decisions

- **Images.** `![alt](path)` alone in a paragraph becomes a block image sent through the same kitty path as display math. An image inside other text stays what it is today, a link. PNG bytes are sent as they are (`f=100`); JPEG is decoded with `zune-jpeg` and re-encoded with the `png` crate already in the tree. No SVG, GIF or remote URLs: those print as links. `zune-jpeg` is the only new dependency (`jpeg-decoder` is the fallback if it misbehaves).
- **Pager.** `--pager` / `-p` spawns `$PAGER` (default `less -R`) and streams the text into it, while image transfers go straight to `/dev/tty`. Placeholder cells are plain text plus SGR, which `less -R` passes through, so images follow the scrolled text. `--tty` exposes the split on its own for `viso --tty FILE | less -R`.
- **Links.** OSC 8 hyperlinks around the link text when stdout is a terminal; the URL in dim after the text otherwise, as today, so files and pipes still show where a link goes. Each link gets one `id=` so a link wrapped over two lines is one hover target.
- **Light terminals.** The background is queried with OSC 11; relative luminance above 0.5 means light. The theme default becomes `auto`: `base16-ocean.dark` or `base16-ocean.light`. Inline-code color gets a light variant. `--theme NAME` and the config key still force a theme.

## Images

`md.rs`

- `Block::Image { alt: String, url: String }` for a paragraph whose only inline is an image, promoted the same way display math is: `inlines()` returns a flag, `push_paragraph` promotes. Images with surrounding text keep becoming `Inline::Link`.

`image.rs` (new)

- `fn load(path: &Path) -> Option<Image { png: Vec<u8>, w: u32, h: u32 }>`. Sniff the magic bytes. PNG: width and height from the IHDR (bytes 16..24, big-endian), bytes passed through untouched. JPEG: `zune_jpeg::JpegDecoder` to RGB8, then `png::Encoder` with `ColorType::Rgb`, eight bits, fast compression. Anything else: `None`.
- Relative paths resolve against the document's directory, against the working directory for stdin.
- Placement: `cols = min(ceil(w / cell_w), avail)`, `scale = cols * cell_w / w`, `rows = ceil(h * scale / cell_h)`, both capped at `kitty::MAX_CELLS`. kitty fits the image into the box preserving the aspect ratio, so the last row may be partly empty.
- ponytail: no downscaling before transfer, so a 12-megapixel photo is a 16 MB escape stream. Add a box-filter resize when a note actually has one.

`render.rs`

- `Block::Image` with images on and a loadable file: transmit, then placeholder rows, exactly like display math. Otherwise one line: `alt` followed by the path in dim.

## Pager mode

`render.rs`

- `Renderer` gets a second sink, `transfers: Box<dyn Write>`, defaulting to the same stdout. Every `kitty::transmit` output goes there: inline lines, display math, images, table cells. Transfers are flushed per formula; the text stays buffered.

`main.rs`

- `--tty`: the transfer sink is the `Tty`'s file.
- `--pager` / `-p`: implies `--tty`. `Command::new` on `$PAGER` split on whitespace, default `less -R`, stdin piped; the renderer writes the text into the child's stdin; wait for the child; exit with its status. Width is the terminal width even though stdout is the pipe. `--pager` without a tty is an error.
- `--no-images` with `--pager` is the plain `less -R` path, nothing special.

Ceilings

- kitty evicts images once its storage quota (default 320 MB) is reached; scrolling back past that shows empty cells. Thousands of formulas fit.
- Images are sent before the pager starts; virtual placements persist until deleted, so order does not matter. Found while checking: kitty keeps image storage per screen buffer, so a pager on the alternate screen shows empty cells. less therefore gets `-X` (and `LESSUTFCHARDEF=10EEEE:p`, less 632+, or it prints the placeholder as `<U+10EEEE>`); other pagers must stay on the main screen themselves.

## Clickable links

`render.rs`

- In `tokens()`, link text words are wrapped as `ESC ] 8 ; id=N ; URL ESC \ word ESC ] 8 ; ; ESC \`, `N` from a counter in the renderer. The `(url)` suffix is emitted only when `hyperlinks` is off.
- `Renderer::new` gains `hyperlinks: bool`; `main.rs` passes `stdout.is_terminal()`, and `--pager` passes true since `less -R` forwards OSC 8.
- SGR 4 underline stays in both modes.

## Light terminals

`term.rs`

- `fg_color()` generalized to `osc_color(n: u8) -> Option<[u8; 3]>`; `bg_color()` is `osc_color(11)`.

`main.rs`, `render.rs`

- `light = 0.2126 R + 0.7152 G + 0.0722 B > 0.5` on channels in 0..1. Theme `auto` resolves to `base16-ocean.light` when light, else `base16-ocean.dark`. Inline code `38;5;180` on dark, `38;5;130` on light; headings stay `1;34`.
- `--debug-term` prints `bg=#rrggbb light=yes|no`.

## Order of work

1. OSC 8 links: unit test on the bytes, manual check in kitty (hover, click).
2. Light terminals: `osc_color`, the luminance split with a unit test, manual check with `kitty -o background=#ffffff`.
3. `--tty`, then `--pager`: a unit test that transfers land in the transfer sink and only placeholders in the text sink; manual `viso -p` on a long note, scroll both ways, resize.
4. Images: PNG first with a unit test on a hand-made 2×2 PNG (IHDR parse, placement math), then JPEG; manual check with a matplotlib figure in a note.
